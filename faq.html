Frequently Asked Questions

Where do these games come from?

  • For Steam, most of the games are donated from the accounts of M.D, D.W, and C.M.
  • For Epic Games, Epic gives out free games on a weekly or faster basis. M.D created the account and will continue to claim game giveaways.
  • Moving forward, the house will have a certain semester gaming budget that can be used to purchase new games.

If I want a game, what should I do?

  • First make sure this game is not already in the CZhared Library
  • Next, use the Wishlist Tool to add the game to the global wishlist.
  • The Network manager will review this wishlist and decide that desired games to buy.

How do I login?

  • The logins are not posted here for security reasons. Logins can be found on the CZ Network Manager Hub.


If you encounter any issues, contact your Network Manager and they can be added to the FAQ.
